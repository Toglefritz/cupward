# Skills

Cupward is a Flutter app (`cupward_app/`). Load the skill that matches the task before starting work. Each skill lives in its own folder as `<name>/SKILL.md`.

| Task | Skill |
| --- | --- |
| Writing or editing any Dart or Flutter code | `flutter-coding-style` |
| Documenting code, writing tests | `documentation-standards` |
| Writing comments, Dartdoc, README text, or any prose | `writing-style` |
| Planning or scoping a feature, adding files or APIs | `development-behavior` |
| Discussing or reviewing a system design | `design-discussion` |
| About to create or edit a Markdown file | `markdown-discipline` |

Several skills usually apply at once. For example, adding a screen uses `development-behavior`, `flutter-coding-style`, `documentation-standards`, and `writing-style`.
